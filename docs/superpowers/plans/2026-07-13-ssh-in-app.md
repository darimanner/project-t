# SSH in the App — Implementation Plan

> Spec: `docs/superpowers/specs/2026-07-13-ssh-in-app-design.md`. Executed inline
> in one pass; this plan records task order and interfaces for resumability.

**Goal:** SSH tabs in the GPUI app: session trait, connection states, host
sidebar backed by core-store, add-host form, Cmd+K palette.

## Task 1: Session trait + adapters

- Create `crates/app/src/session.rs`: `trait Session: Send` with
  `take_reader/write_all/resize/kill`; `LocalSession` (PtySession),
  `RemoteSession` (SshSession). `LocalSession::spawn(rows, cols)`,
  `RemoteSession::connect(SshConfig)` (blocking).
- Add `core-ssh`, `core-store` deps to `app/Cargo.toml`.

## Task 2: TerminalView on dyn Session + connection states

- `terminal_view.rs`: replace `Arc<Mutex<PtySession>>` with
  `SharedSession = Arc<Mutex<Box<dyn Session>>>`; add
  `enum TabState { Connecting(String), Live, Failed(String) }`.
- Constructors: `new_local(window, cx)` and `new_ssh(label, SshConfig, window, cx)`
  (background thread connects, then updates entity to Live/Failed and starts
  the reader).
- `terminal_element.rs`: swap pty field for `SharedSession` (resize goes through
  the trait).
- Verify: build + local tab works; hardcoded env-driven SSH tab connects.

## Task 3: text_input widget

- `text_input.rs`: `InputState` (string editing: insert/backspace) as pure
  testable struct + `TextInput` render helper (focused border, placeholder,
  masked mode). Unit tests for editing.

## Task 4: Store wiring + sidebar

- `workspace.rs`: open `Store` at `~/Library/Application Support/project-t/store.db`;
  sidebar column (200px) listing hosts, click → `new_ssh` tab (password from
  keyring / key path from row), hover × deletes host + secret, “+ add host”
  opens form. Store failure → error line in sidebar.

## Task 5: Add-host form

- `host_form.rs`: modal with label/host/port/user/auth-toggle/secret fields on
  top of `InputState`; Tab cycles focus, Enter validates + saves (SQLite +
  keyring), Esc closes. Pure `validate()` with unit tests.

## Task 6: Command palette

- `palette.rs`: Cmd+K overlay — input + substring-filtered host list, ↑/↓/Enter/Esc.
  Pure `filter_hosts()` with unit tests. KeyBinding `cmd-k` → `TogglePalette`.

## Task 7: Final verification

- `cargo test --workspace`, clippy clean, manual run: local tab, add host,
  connect, wrong password → Failed, palette connect, delete host. Commit.
